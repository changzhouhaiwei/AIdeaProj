# 棋子素材导出规范（移动端防锯齿）

## 1) 尺寸倍率
- 基准：按“运行时最大显示尺寸”的短边计算。
- 最低：源图短边 >= `1.5x` 最大显示短边。
- 理想：源图短边 >= `2.0x` 最大显示短边。
- 当前项目建议值（按现有布局参数）：
  - 棋盘棋子 + 顶部目标区综合最大显示边约 `92px`。
  - 最低短边建议 `138px`，理想短边建议 `184px`。

## 2) 描边与边缘
- 不建议纯黑硬边（`#000000` 单像素硬描边）直接导出。
- 建议改为深灰/深棕描边（例如 `#2B2B2B` / `#3A2A1F`）+ 2~3px 软过渡抗锯齿边缘。
- 曲线边缘（花瓣、果实弧线）优先做亚像素平滑，避免“台阶状”锯齿。

## 3) 导出格式
- 使用 PNG（保留 alpha 通道），避免二次有损压缩导致边缘脏点。
- 同一套棋子保持统一色域与对比度，避免局部边缘过锐。

## 4) 运行时约束
- 本项目运行时默认禁止放大采样（避免小图被拉大后更锯齿）。
- 素材策略应尽量保证“源图 >= 显示尺寸”，以 downscale 为主。

## 5) 验收截图建议
- 机型：至少一台 Android（中端）+ 一台 iPhone（高 DPR）。
- 场景：棋盘中曲线较多的图案（如花朵/水滴/橙子）至少各 1 张对比图。
- 判定：边缘台阶感明显下降，且不出现整体发糊。

# Sort

用 Unity 打开 `SortClient`，不要打开仓库根目录。

| 目录 | 作用 |
| --- | --- |
| `SortClient` | Unity 2022.3.62f3 客户端 |
| `SortProfile` | Luban 配表 |
| `SortAndroid` | Android 工程壳，没有 iOS |
| `docs` | 目录和框架说明 |

玩法目录是空的，不包含 Tile 的关卡和棋盘。业务模块在 `SortClient/Assets/Features`：

1. 连胜活动
2. 七日签到
3. 设置
4. 用户信息
5. 玩法（空）

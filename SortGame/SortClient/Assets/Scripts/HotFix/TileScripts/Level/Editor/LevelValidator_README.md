# 关卡瓦片数量检测器使用说明

## 功能概述

关卡瓦片数量检测器是一个Unity编辑器工具，用于检测所有关卡中的瓦片数量是否符合游戏规则。游戏要求每个关卡中的瓦片数量必须是3的倍数，以便玩家能够组成完整的瓦片集合。

## 使用方法

### 1. 打开检测器
- 在Unity编辑器中，选择菜单 `Tools > 关卡验证器 > 瓦片数量检测`
- 或者通过代码调用 `LevelValidatorWindow.ShowWindow()`

### 2. 选择关卡数据库
- 在检测器窗口中，选择包含所有关卡的 `LevelDatabase` 资源
- 如果未自动加载，可以点击"重新加载"按钮

### 3. 开始检测
- 点击"开始检测所有关卡"按钮
- 系统将遍历所有关卡并验证瓦片数量
- 检测过程中会显示进度条

### 4. 查看结果
- 检测完成后，会显示所有关卡的验证结果
- 可以勾选"仅显示错误"来只查看有问题的关卡
- 每个关卡显示：
  - 关卡索引和名称
  - 当前瓦片数量
  - 可组成的集合数量
  - 验证状态（正确/错误）
  - 错误信息（如有）

### 5. 生成修复报告
- 点击"生成修复报告"按钮
- 系统会在Console窗口中输出详细的修复建议
- 包括每个问题关卡的具体修复方案

## 验证规则

### 瓦片数量规则
- 每个关卡中的瓦片总数必须是3的倍数
- 如果瓦片数量除以3余1，需要再添加2个瓦片
- 如果瓦片数量除以3余2，需要再添加1个瓦片

### 示例
- 1个瓦片 → 需要添加2个瓦片（总共3个，组成1个集合）
- 2个瓦片 → 需要添加1个瓦片（总共3个，组成1个集合）
- 4个瓦片 → 需要添加2个瓦片（总共6个，组成2个集合）
- 5个瓦片 → 需要添加1个瓦片（总共6个，组成2个集合）

## 修复方法

### 手动修复
1. 在检测器窗口中点击"查看关卡"按钮，选择有问题的关卡
2. 点击"打开编辑器"按钮，打开关卡编辑器
3. 在关卡编辑器中，在空位置添加相应数量的瓦片
4. 确保添加后瓦片总数是3的倍数

### 自动修复（实验性功能）
- 勾选"自动修复模式"选项
- 点击有问题的关卡旁边的"自动修复"按钮
- 注意：由于技术限制，自动修复功能可能无法完全工作，建议使用手动修复

## 技术实现

### 核心类
- `LevelValidatorWindow`: 主窗口类，继承自EditorWindow
- `LevelValidationResult`: 验证结果数据结构
- `LevelDatabase`: 关卡数据库，包含所有关卡数据
- `LevelData`: 单个关卡数据，包含图层和瓦片信息

### 验证逻辑
```csharp
// 获取关卡中所有瓦片数量
int tileCount = levelData.GetAmountOfFilledCells();

// 检查是否为3的倍数
if (tileCount % 3 != 0)
{
    // 计算需要添加的瓦片数量
    int tilesNeeded = (tileCount % 3 == 1) ? 2 : 1;
    // 标记为错误
}
```

### 数据结构
- `Layer[]`: 关卡中的图层数组
- `LayerRow[]`: 每个图层中的行数组
- `CellData[]`: 每行中的单元格数组
- `CellData.IsFilled`: 单元格是否被瓦片填充

## 注意事项

1. **数据安全**: 检测器只读取关卡数据，不会修改原始数据
2. **性能**: 大量关卡检测可能需要一些时间，请耐心等待
3. **备份**: 在修复关卡前，建议备份原始关卡数据
4. **验证**: 修复后请重新运行检测器确认问题已解决

## 扩展功能

### 可能的改进
1. 批量修复功能
2. 导出检测报告到文件
3. 集成到CI/CD流程
4. 支持更多验证规则
5. 可视化修复建议

### 自定义验证规则
可以通过修改 `LevelValidationResult.ValidateLevel()` 方法来添加更多验证规则，例如：
- 检查空图层
- 验证特效数量
- 检查关卡尺寸
- 验证难度设置

## 故障排除

### 常见问题
1. **找不到关卡数据库**: 确保项目中存在LevelDatabase资源文件
2. **检测结果为空**: 检查关卡数据库是否包含有效的关卡数据
3. **编辑器无法打开**: 确保LevelEditorWindow脚本存在且可访问

### 调试信息
- 所有检测结果都会输出到Console窗口
- 可以使用Unity的Debug.Log来查看详细的验证过程
- 错误信息会显示具体的瓦片数量和修复建议

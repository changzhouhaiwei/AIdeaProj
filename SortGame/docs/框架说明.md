# Sort 框架

从 Tile2 迁过来的是四套框架。Tile 的关卡、棋盘、活动和 iOS 工程没有迁。

## 配表

表在 `SortProfile`。Unity 里打开 `Assets/Luban.asset`，点生成。代码写到 `SortClient/Assets/Scripts/HotFix/GameConfig`，json 写到 `SortClient/Assets/CABRes/Configs`。

运行时用 `ConfigHelper.Initialize()` 读表。

现有表：

| 表 | 模块 |
| --- | --- |
| `WinStreak.xlsx` | 连胜活动 |
| `SevenDaySign.xlsx` | 七日签到 |
| `Settings.xlsx` | 设置 |
| `UserInfo.xlsx` | 用户信息 |
| `LocalizationConfig.xlsx` | I2 文案 |

没有玩法表。`__beans__.xlsx` 的 `*fields` 表头必须保持 `H1:L1` 合并，`__enums__.xlsx` 保持 `G1:K1` 合并，否则 Luban 读不出字段。

语言包菜单：`游戏工具/一键导出语言包`。脚本在 `SortClient/Tools/Localization`。

## UI

框架在 `SortClient/Assets/Scripts/FishFramework`。界面生成目录是 `Assets/Features`，基类在 `Assets/Features/GeneratedBaseUI`。

根节点预制体仍约定为 `Assets/CABRes/Prefabs/Main/UIRoot.prefab`，这个预制体要自己做。

依赖：DOTween、Odin、SuperScrollView、I2、TextMeshPro。

## 资源

`Assets/xasset` 管 AssetBundle。`ResourceModule` 在初始化时调用 `Versions.InitializeAsync()`。业务加载走 `ResourceModule.LoadAsset`。

## SDK

只留 Android。

- C#：`Assets/Scripts/HotFix/SDK/GameSdk-Android-ZZXZ`
- 回调：`GameSDKCallbackHub`
- 启动挂点：`SortSdkHost`。它会创建 `UnityCallbackDelegate` 和 `GPSDKMgr`，这两个名字是原生 `UnitySendMessage` 的目标，不能改。
- Java：`Assets/Plugins/Android`

`CustomApplication` 里的 AppsFlyer key 和数数 appId 是占位符，要换成 Sort 自己的。

埋点从 `GameModule.DataAnylasis` 进数数、AppsFlyer 和 Firebase。Tile 那套关卡埋点没有迁。

## Android

`SortAndroid` 只保留 Gradle 和 Java 壳。母包资源、il2cpp、so 和符号表要等 Unity 重新导出，不要把 Tile 的包拷进来。

- 包名：`com.sort.game`
- AdMob 现在是 Google 测试 App ID
- 瀑布流广告位是空的
- `launcher/google-services.json` 要自己放，放上之后才会套 Firebase 插件
- GameSDK 私有仓库用环境变量 `ZZXZ_MAVEN_USER` 和 `ZZXZ_MAVEN_PASSWORD`

导出：Unity Build Settings 里选 Android，Export Project，输出到 `SortAndroid`。

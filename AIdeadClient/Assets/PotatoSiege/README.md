# 土豆围城（PotatoSiege）

Brotato-like 十职业垂直切片，独立于其他模块。

## 运行

1. 菜单 **PotatoSiege → Setup Scene And Sprites**
2. 打开 `Assets/PotatoSiege/Scenes/PotatoSiege.unity`
3. 按 Play

## 操作

- **WASD / 方向键**：移动
- **右键**：朝鼠标方向移动
- **自动瞄准射击**
- **空格 / Q / 中键**：职业主动技
- 波次结束后在商店买武器/道具，可重随；赌徒可「赌一把」

## 资源

- 角色/僵尸精灵：Kenney Top-down Shooter（CC0）
  - https://kenney.nl/assets/top-down-shooter
  - 见 `Art/CREDITS.txt`

## 内容

- 10 职业 + 被动/主动（见 `Docs/土豆兄弟_十职业策划案.md`）
- 20 波、商店、升级、异常状态（火/毒/电）

# Chapter1 Farm（徽章式土豆）

第一章农场战斗竖切：土豆角色 + 黄瓜敌人。

## 运行

1. 打开 `Assets/Art/Role/Scenes/Chapter1_Farm.unity`
2. 按 Play  
   （若场景缺失，菜单 **Art/Role/Create Role_Potato Prefab** → **Art/Role/Setup Chapter1 Farm Scene**）

## 操作

- **WASD**：移动
- **鼠标**：瞄准
- **LMB / Space**：射击（有敌人时也可自动射击）

## 资源

- 角色分层：`Assets/Art/Role/Parts/`
- 预制体：`Assets/Art/Role/Prefabs/`
- 农场背景：`Assets/Art/Bg/bg_battle_farm.png`
- 玩法脚本：`Assets/Art/Role/Scripts/`

# Wheel UI

竖屏幸运转盘。关闭钮 / 标题牌复用 `Common/`。

## 复用

| sprite | 来源 |
|--------|------|
| `Common/btn_close.png` | Settings_RefStyle 同款关闭 |
| `Common/title_banner.png` | Settings_RefStyle 标题牌 |

## 专用 Parts

`panel_bg` / `wheel_disk` / `wheel_pointer` / `btn_spin` / 货币条与图标等。

## 构建

Unity MCP 或菜单 **Art/UI/Build Prefab From Layout** → `layout.json` → `Prefabs/UI_Wheel.prefab`

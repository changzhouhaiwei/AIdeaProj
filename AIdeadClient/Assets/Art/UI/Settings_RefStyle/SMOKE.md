# Settings_RefStyle（测试版）

**目的**：对照截图木纹/羊皮纸风格做一版，**不使用**工程徽章土豆风。  
正式项目仍以 `Settings/`（徽章风）为准。

## 产物

- `ref_style.png` — 你的截图参考  
- `mockup.png` — 木纹风格整屏效果图  
- `layout.json` / `ui_structure.json` — 与 Settings 同结构  
- `Parts/` — 木纹面板、标题牌、红关闭、绿金开关、列表图标等  

## Unity

**Art/UI/Build Prefab From Layout** → 选  
`Assets/Art/UI/Settings_RefStyle/layout.json` →  
`Prefabs/UI_Settings_RefStyle.prefab`

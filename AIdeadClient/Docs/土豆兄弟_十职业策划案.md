# 《土豆围城》十职业版 · 策划案（MVP）

> 定位：复刻《土豆兄弟》（Brotato）核心体验——顶视角生存射击 + 局内成长 + 商店构筑。  
> 范围：10 个可玩职业，约 20 波一局，手机/PC 均可（默认双摇杆）。  
> 目标时长：单局 12–18 分钟。

---

## 1. 一句话卖点

你是一颗被改造的土豆战士。每波清怪攒钱，商店里拼出离谱 Build，撑到第 20 波。

---

## 2. 核心循环

```
选职业 → 第 N 波开战 → 移动/射击/拾取 → 倒计时结束结算
→ 商店（买武器 / 道具 / 重随）→ 下一波
→ 第 20 波 Boss → 结算评分
```

### 2.1 一波内节奏

| 阶段 | 时长（参考） | 说明 |
|------|--------------|------|
| 开战 | 0–5s | 敌人从地图边缘涌入 |
| 高压 | 中段 | 精英偶发，逼走位 |
| 收尾 | 最后 5s | 怪潮略减，方便捡经验/材料 |
| 结算 | — | 经验→等级；金钱入账；进商店 |

- 单波时长：**60 秒**（固定，不做随波增长，降低学习成本）。
- 怪物总量随波次上升；第 10 / 15 / 20 波为 **精英波 / 小 Boss / 终局 Boss**。

### 2.2 死亡与重开

- 生命归零 → 本局失败，保留本局击杀/金钱统计，可快速重开同职业。
- 不做中途存档（MVP）。

## 3. 基础系统骨架

### 3.1 六维属性（全局）

| 属性 | 作用 | 默认上限思路 |
|------|------|--------------|
| 最大生命 | 血量池 | 软上限 + 道具突破 |
| 生命回复 | 每秒回血 | 低起步，职业差大 |
| 伤害 | 全武器乘区 | 百分比为主 |
| 攻速 | 攻击间隔 | 有硬顶（防刷屏） |
| 移速 | 走位 | 有硬顶 |
| 射程 | 子弹/近战判定距离 | 近战职业可负相关设计 |
| 暴击率 / 暴击伤害 | 爆发 | 暴击率软顶约 60% |
| 拾取范围 | 经验/材料吸附 | 后期 Build 舒适度 |
| 工程（可选） | 炮塔/地雷等结构体强度 | 仅部分职业吃满 |
| 幸运 | 商店稀有度、精英掉落 | 数值要克制 |

> MVP 可先做：**生命 / 回复 / 伤害 / 攻速 / 移速 / 射程 / 暴击 / 拾取 / 幸运** 九项；工程可二期。

### 3.2 武器槽

- 默认 **6 个武器槽**（与土豆兄弟同量级）。
- 同名武器可叠加等级（或合并为更高等级），商店出现「升级」比「新开槽」更稳。
- 近战 / 远程 / 元素（火毒电）三类标签，用于职业克制与道具联动。

### 3.3 道具（被动）

- 商店购买，无槽位上限（或软上限 20，防 UI 爆炸）。
- 分三类：**属性纯加** / **机制改变** / **风险收益**。
- 每个职业有 2–4 个「亲和道具」（打折或更高出现率），强化身份，而不是只靠初始属性。

### 3.4 商店

- 每波后刷新一次；可花金钱 **手动重随**（费用随次数上涨）。
- 货架：武器 4 + 道具 4（可调）。
- 货币：击杀金币 + 波次通关奖金；未花完可滚动到下波（鼓励赌下一波货）。

### 3.5 地图与操作

- 封闭方形/略不规则竞技场，无复杂地形（MVP）。
- 移动 + 自动瞄准最近敌人（或右摇杆瞄准）；近战职业依赖贴脸判定。
- 可选：闪避键（有 CD）——仅给部分职业初始带，避免全员同质。

## 4. 十个职业设计

设计原则：

1. **一句话玩法**，玩家 3 秒能懂。
2. **一个强项 + 一个硬伤**，逼构筑做取舍。
3. **独特机制**优先于「数值换皮」。
4. 难度星级仅作选人参考，不做隐藏强度碾压。

## 7. 数值调参原则（防崩）

1. **职业强度差控制在 ±15% 通关率**（同玩家水平下）；超出则削机制而非只削面板。
2. 商店物价曲线：前期便宜养成，中期抉择，后期「买不买得起关键件」。
3. 攻速硬顶、弹幕数量软顶，保证低端机帧率。
4. 每个职业至少准备 **2 条官方推荐 Build 路线**（用于新手引导文案，不做强制）。

## N2. 核心公式

### N2.1 伤害

```
最终伤害 = 武器基础伤害
         × (1 + DMG% + 标签伤害% + 职业修正%)
         × 暴击倍率（未暴击 = 1）
         × 易伤乘区（拳手连打等）
         × 专注/狂怒等状态乘区
         × (1 - 敌人减伤)
```

- 暴击判定：`roll < CRIT%` → 乘 `CRITD/100`。
- 多把武器独立计算、独立冷却；同帧多段命中允许，但单体 DPS 需用 N7 验收。

### N2.2 攻速

```
实际攻击间隔(秒) = 武器基础间隔 / (1 + ASPD%/100)
最低间隔硬顶 = 0.08 秒（防弹幕炸机）
```

### N2.3 承伤

```
受伤 = 原始伤害 × (1 - 护甲减伤%) × (闪避失败)
护甲减伤% = ARMOR / (ARMOR + 50)
```

### N2.4 护盾（医生等）

- 护盾优先扣；护盾不吃回复，只吃「过量治疗转化」。

# 技能设计

> 本作为「构筑向」，**不以技能栏连招为主**。  
> 每个职业 = **1 条被动核心技** + **0–1 条主动技（可选键）** + **武器普攻**。  
> 主动技默认映射：手游右侧技能键 / PC 空格或 Q。

### 通用技能规则

1. 被动：整局常驻，数值随道具/属性成长（写明吃哪些属性）。
2. 主动：有 CD；波间商店不重置 CD（防卡 CD 清 Boss）；死亡清空增益。
3. Buff 图标：专注、连打层数、狂怒、护盾值需在 HUD 可见。
4. 技能不单独升级；强度跟属性与道具走。
